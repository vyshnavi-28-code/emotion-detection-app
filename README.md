# Emotion Detection App 😊

## Overview

The Emotion Detection App is a Machine Learning and Computer Vision project that detects human emotions from text. Using a webcam feed, the application analyzes text and predicts the user's emotional state.

The system can recognize emotions such as:

- Happiness 😊
- Sadness 😢
- Angry 😠
- Surprise 😲
- Fear 😨
   
  

This project demonstrates the practical application of Artificial Intelligence, Deep Learning, and Computer Vision in emotion recognition systems.

---

## Features

✅ Text-based emotion detection

✅ Emotion classification using Machine Learning

✅ NLP-based text processing

✅ TF-IDF feature extraction

✅ Logistic Regression classification

✅ Supports six emotion categories: Joy, Sadness, Love, Anger, Fear, and Surprise

✅ User-friendly and interactive Streamlit interface

✅ Instant emotion prediction for user-entered text

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- Streamlit
